## 🌐 APIs Consumidas

Este projeto consome APIs **REST** (Representational State Transfer) que seguem os princípios:
- ✅ Uso do protocolo HTTP (método GET)
- ✅ Retorno de dados em formato JSON
- ✅ Arquitetura stateless (sem estado)
- ✅ URLs baseadas em recursos
- ✅ Códigos de status HTTP padronizados

**APIs utilizadas:**
- Brasil API (REST)
- AwesomeAPI (REST)
- ExchangeRate-API (REST)
